# Aufnahmen für die PDF-Layouts

Die Aufnahme zeigt die drei A4-Vorlagen im Benutzermenü einer lokalen Akribos-Installation. Bei jeder Vorlage ist die erste Seite desselben Beispiels „Vom Hören zum Tun“ zu sehen. Die PDF-Seiten wurden mit Poppler bei 155 dpi gerastert. Die letzte Einstellung zeigt einen PDF-Export aus dem vorangehenden Editor. Für die Aufnahme werden ausschließlich Beispieldaten verwendet.

Die Fokusbereiche stehen in [episode.json](../episode.json). Die Vorlage der Aufnahme lässt sich unter **Mein Konto → PDF-Export** auswählen. Der Anzeigename steht unter **Profil & Sicherheit**.
