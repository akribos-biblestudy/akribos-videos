# Aufnahmen für den App-Rundgang

Die Screenshots stammen aus den aktuellen Flutter-Widgets der Akribos-App. Ein Widget-Test führt die Schritte mit öffentlichen Bibeltexten und fiktiven Notizen aus. Das Fenster hat 414 × 850 logische Pixel und wird mit zweifacher Pixeldichte aufgenommen. Die Stellenwahl zeigt die verbreiterte Buchspalte. Die Wortstudie verwendet Johannes 3,16, auf die Psalmansicht folgt sie als eigenständiges Beispiel.

Die Fokusbereiche stehen in [episode.json](../episode.json).
